WorkBuddy 手机登录

在这个页面里用手机号登录 CodeBuddy，直接拿到签到要用的令牌，不用再回电脑导出。

① 登录（手机号 + 验证码）

装了 Loon 插件的：登录完会自动跳回本页、顶部弹出结果。没装的：登录完把地址栏那一整条 URL 拷回来，粘到第 ② 步。

登录完没有任何提示？看这里

最可能是 Loon 没拦到这次回调，逐条查：

  1. Loon → 插件 → 把 WorkBuddy 插件更新一次，确认里面有 WorkBuddy手机登录 这一条。
  2. Loon 设置里 MITM 开关要打开，且 [MITM] 的 hostname 含 www.codebuddy.cn。
  3. 不想折腾 Loon：登录完复制地址栏 URL，粘到第 ② 步，这一页自己换令牌。
  4. 跳到 …/account/?… 之后屏幕上只有一段 {"message":"Your IP address is not allowed"}？没关系 —— 地址栏那条 URL 里带着 code=，整段复制到第 ② 步就能换到令牌。
  5. code 只有约 1 分钟有效期，超时了重新点一次登录。
高级（一般不用改）

client_id：

PKCE：S256（强制开启，关不掉） —— CodeBuddy 服务端要求，不带会被直接打回。 verifier 会被编进 state 一起回到回调 URL 里，所以走 Loon 自动模式也不用往 BoxJS 填 WorkBuddy_LoginVerifier。

② 粘贴回调地址

在这一页换不了？普通浏览器里 CodeBuddy 的令牌接口不带跨域许可，浏览器会拦下这次请求（Load failed / Failed to fetch）—— 不是地址的问题。这时改用手机上的 BoxJS：把这条 URL 粘进 WorkBuddy 应用里的「登录回调地址」保存，再点「立即签到一轮（手动运行）」，由脚本在手机本地换令牌并写进账号池（这条路不需要 MITM）。

③ 账号池（粘进 BoxJS「账号池」）

BoxJS → 应用 → WorkBuddy 自动签到 → 账号池 → 粘进去 → 点右下角蓝色按钮保存。

④ 续期（access_token 过期时用）

还没有登录记录。

⑤ 全自动模式（可选）

在 Loon 里装好本仓库插件后，插件会拦下这次登录回调：把令牌直接写进 BoxJS 账号池、顺手验证能不能签到，然后自动把浏览器送回本页。这时你只要：

  1. PKCE 不用管（页面强制开启 S256，verifier 会跟着回调一起带回来）
  2. 点登录 → 输手机号 + 验证码
  3. 等浏览器跳回本页 → 顶部出现 ✅ 登录成功 / ⚠️ 令牌未验证通过 / ❌ 登录没有完成 的横幅（Loon 和 BoxJS 也会各收到一条通知）

不装 Loon 也能全自动（「交棒」模式）：登录完把地址栏那条 URL 整段复制 → 手机 BoxJS → WorkBuddy 应用 →「登录回调地址」→ 粘贴 → 保存 → 再点「立即签到一轮（手动运行）」。这一步由脚本在手机本地把 code 换成令牌、 验证能不能签到、写进账号池，成败都会弹通知（换令牌是脚本自己发出去的请求，不受浏览器跨域限制）。 换完那个字段会自动清空，之后正常跑就行。

这是怎么运作的

  1. 登录走的是 codebuddy.cn 自己的 Keycloak（realm copilot），用的公开客户端 account-console，不碰任何第三方凭据。
  2. 令牌换回来之后，本页把它整理成 BoxJS 账号池的格式（含 refresh_token），方便你一键复制。
  3. 令牌只能由签发它的客户端续期。account-console 是公开客户端，所以这页换出来的令牌 以后能自己续期；电脑版导出的旧令牌（client console）不行，过期只能重登。

令牌是本机数据，只保存在你的浏览器里，不会被上传到任何地方。Pages 上会记住（localStorage）；如果是 www.codebuddy.cn/wb-login 这个由 Loon 直接提供的地址，为了不同源暴露，令牌只留在内存里（关掉页面即消失，要复用就复制走）。

不想用这一页？也可以直接在手机浏览器登录官方页面：www.codebuddy.cn（但官方登录的令牌换不到手，还需要配合 Loon 抓包）。
